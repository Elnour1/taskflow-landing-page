# ✅ TaskFlow — Smart Task Management Landing Page

**TaskFlow** is a modern, responsive one-page web application designed to help students, freelancers, and teams organize their daily tasks and amplify their focus. Built with a **UX-first approach** before translating the design system into modular **React** components.

---

## 🎯 Problem Statement & UX Strategy

Instead of jumping straight into coding, the project started by identifying real user pain points and designing targeted UI solutions:

1. **Students (Overwhelmed by complex tools):**
   * **Solution:** A frictionless **Quick-Add** task input and minimalist interface.
2. **Freelancers (Missed deadlines & mixed priorities):**
   * **Solution:** Color-coded priority tags (`Work`, `Urgent`, `Done`) and automated reminders.
3. **Team Leads (Lack of task ownership visibility):**
   * **Solution:** Clear status tracking and collaborative workspace previews.

---

## 🗺️ User Flow

* **New Visitor Flow:** Landing Page $\rightarrow$ Value Discovery (Hero & Interactive Demo) $\rightarrow$ Social Proof (Testimonials) $\rightarrow$ Plan Selection (`Start Free` / `Pro` / `Team`).
* **Returning User Flow:** Direct access via the sticky navigation bar (`Login`) to jump straight into their workspace.

---

## 🎨 UI Design System

* **Color Palette:**
  * Primary Brand: `Indigo (#4F46E5)` for focus, trust, and primary CTAs.
  * Neutral Surfaces: `White (#FFFFFF)` & `Slate-50 (#F8FAFC)` for clean visual breathing room.
  * Semantic Accents: `Emerald (#10B981)` for completed tasks and `Amber (#F59E0B)` for urgent tags.
* **Layout & Hierarchy:** Responsive 12-column grid system, clear typographic scale, and focal-point highlighting on the **Pro** pricing tier.

---

## 🛠️ Tech Stack & Features

* **React (JSX):** Modular component architecture (`Navbar`, `Hero`, `Features`, `Testimonials`, `Pricing`, `Footer`).
* **Tailwind CSS:** Mobile-first responsive design with utility-first styling.
* **Interactive Task Preview:** Live stateful task list in the Hero section allowing visitors to add and toggle tasks in real time.
* **Scroll Reveal Animations:** Lightweight `IntersectionObserver` wrapper for smooth section transitions on scroll.
